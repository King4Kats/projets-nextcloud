# Journal des versions

Versions des deux applis : socle `temonia_pilotage` / interface `temonia_saisie`.

## 0.13.0 / 0.27.0 — 2026-11-10

- Première publication open source (AGPL-3.0-or-later), avec démo Docker, tests et documentation.
- Libellés neutres : le nom de la structure et des catégories (« Partenaires »…) se règlent par
  `occ config:app:set temonia_pilotage libelles`, plus rien n'est propre à une association dans le code.
- Planneur refait : zooms semaine à 3 ans, ligne du jour, libellés collants, tout déplier / replier.

Les versions précédentes ont été développées et utilisées en interne.
